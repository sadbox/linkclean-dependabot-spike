# linkclean-dependabot-spike

Throwaway repository for the M2 gate of
[Espresso-Aficionados/linkclean](https://github.com/Espresso-Aficionados/linkclean)
(design §11.10): does Dependabot's `gitsubmodule` ecosystem work as the
upstream-change detector? Safe to delete once the gate is recorded.

The `spike-upstream` branch of this repository stands in for an upstream the
maintainer controls; its commits are backdated so a cooldown does not delay the test.
